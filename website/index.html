A loading screen for the gap Steam doesn't cover.

Double-click a game shortcut and there's often a long, silent pause before anything happens. Steam Loading Popups shows a simple "Game Loading…" popup the moment you launch, and closes itself the instant the game actually starts.

What it does

A tiny background app that wraps your existing Steam desktop shortcuts — nothing more.

⏳

Loading popup

Shows a spinner and the game's name the instant you launch, so you know something is actually happening.

✓

Closes itself

Watches Steam's own "running" signal and disappears the moment the game has actually started — no guessing, no timers to configure.

↺

Fully reversible

Converting a shortcut keeps its name and icon, and backs up the original so you can restore it any time from the same setup tool.

📌

Pin to taskbar

Optionally pin a converted shortcut straight to the taskbar, just like any other program.

How it works

One quick setup step, then it just works from your existing shortcuts.

1

Install & run setup

Install the app, then open "Steam Loading Popups" from the Start Menu. It scans your Desktop for existing Steam shortcuts.

2

Convert your shortcuts

Check the games you want and click Convert. Each shortcut keeps its name and icon — only what it launches changes.

3

Launch as normal

Double-click the shortcut like you always have. The popup appears, then gets out of the way once the game is up.
